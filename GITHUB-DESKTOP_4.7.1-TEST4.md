Website 4.7.1-TEST4: Desktop-Besucherfehler korrigiert

- Worttrennung in Highscore-Wettbewerbsnamen verhindert

- Keine Änderungen an Fachlogik oder Navigation

## Schritt für Schritt

1. Update-ZIP in einen neuen leeren Ordner entpacken.
2. Den Ordner `DATEIEN_FUER_GITHUB` öffnen.
3. Alle darin enthaltenen Dateien markieren und in den Stammordner des lokalen GitHub-Repositories kopieren.
4. Bei Windows „Dateien im Ziel ersetzen“ bestätigen.
5. GitHub Desktop öffnen und das Repository `the-old-smugglers-club` sowie Branch `main` kontrollieren.
6. Prüfen, dass ausschließlich die in der Dateiänderungsliste genannten Website- und Dokumentationsdateien erscheinen.
7. Die oben angegebene Summary eintragen; Description optional übernehmen.
8. `Commit to main` anklicken.
9. `Push origin` anklicken.
10. Unter GitHub → Actions den Pages-Lauf kontrollieren. Bei GitHub-Störung keinen neuen Commit erzeugen; vorhandenen Lauf abwarten bzw. einmalig neu ausführen.
11. Nach erfolgreichem grünen Deployment bis zu 10 Minuten warten.
12. `VERSION.txt` direkt prüfen: Es muss `4.7.1-TEST4` angezeigt werden.
13. Desktop mit Strg+F5 neu laden, Mobilbrowser vollständig schließen und neu öffnen.
14. Testprotokoll abarbeiten.
