# Website 4.7.0-RC6-HF6-TEST

Gezielter Hotfix für die Darstellung der Spielpaarungen in der Spieltagskachel.

## Änderung

Die mehrfach vorhandenen und widersprüchlichen Desktop-CSS-Regeln wurden bereinigt. Es gilt nur noch eine abschließende Regel:

`[Heimwappen] Mannschaft A – Mannschaft B [Auswärtswappen]`

Die Wappen stehen unmittelbar am zugehörigen Mannschaftsnamen; die Paarung wird als geschlossene Einheit zentriert.

## Unverändert

Grid, Kachelgröße, Navigation, Spielbetriebsdaten, Countdown, Highscore und JavaScript-Logik.
