## Schritt-für-Schritt-Anleitung
1. Das Update-ZIP in einen neuen leeren Ordner entpacken.
2. Den entpackten Ordner öffnen. Nicht den Ordner selbst in das Repository kopieren, sondern ausschließlich dessen Inhalt.
3. Alle enthaltenen Dateien in den Stammordner des lokalen GitHub-Repositories kopieren.
4. Windows bei `index.html` und `VERSION.txt` mit **Dateien im Ziel ersetzen** bestätigen.
5. GitHub Desktop öffnen und das Repository `the-old-smugglers-club` auswählen.
6. Unter **Changes** prüfen, dass `index.html` und `VERSION.txt` geändert sowie die vier Dokumentationsdateien neu erkannt werden.
7. Keine unerwarteten Löschungen akzeptieren.
8. Die oben angegebene Commit Summary eintragen. Die Description kann zusätzlich eingefügt werden.
9. **Commit to main** anklicken.
10. Danach **Push origin** anklicken.
11. Mindestens 10 Minuten warten. GitHub Pages benötigt in diesem Projekt zeitweise etwa 10 Minuten.
12. Desktop: Website öffnen und `Strg + F5` drücken.
13. Mobil: Browserseite neu laden; bei altem Stand Browser vollständig schließen und erneut öffnen.
14. Direkt `https://the-old-smugglers-club.de/VERSION.txt` prüfen. Dort muss `4.7.1-TEST3` stehen.
15. Das beigefügte Testprotokoll vollständig abarbeiten.
