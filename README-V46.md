# Version 2.46 – Datenpflege & Prüfprotokoll

Diese Version schließt die zentrale Datenvereinheitlichung um einen kontrollierten Pflege- und Diagnosebereich ab.

## Neu

- Gemeinsame Anzeige der Datenstände der vier zentralen Wettbewerbsquellen.
- Downloadbares JSON-Prüfprotokoll mit Strukturstatus, Mengen, Fehlern und Hinweisen.
- Keine automatische oder verdeckte Veränderung der Spieldaten.
- Responsive Darstellung im bestehenden Holz-, Leder- und Messingdesign.

## Pflegehinweis

Die eigentlichen Inhalte werden weiterhin in den zentralen JSON-Dateien gepflegt. Nach einer Änderung zeigt die Konsistenzprüfung mögliche Referenz- oder Strukturfehler direkt auf den Wettbewerbsseiten an.
