# Version 2.40 – Wettbewerbs-Dashboard

Diese Version schließt die gemeinsame Ausbaustufe der Wettbewerbsseiten ab.

## Neu

- Auf jeder Wettbewerbsseite steht eine aufklappbare Gesamtlage aller acht Wettbewerbe bereit.
- Die Übersicht zeigt je Wettbewerb den erfassten Umfang, terminierte Spiele, beendete Spiele, den nächsten offenen Eintrag und den aktuellen Bereitschaftsstatus.
- Der aktive Wettbewerb ist in der Matrix eindeutig gekennzeichnet und alle Wettbewerbe sind direkt verlinkt.
- Sämtliche Werte werden ausschließlich aus `spieldaten.json` berechnet.
- Die Übersicht dient zugleich als Kontrollansicht für die anschließende Vereinheitlichung der zentralen Datenpflege.

## Unverändert

Grundlayout, Startseitenraster, Kachelgrößen, Abstände und bereits freigegebene Bereiche wurden nicht verändert.
