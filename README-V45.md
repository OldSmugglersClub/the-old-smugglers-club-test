# Version 2.45 – Zentrale Konsistenzprüfung

Das gemeinsame Datenmodell prüft Wettbewerbe, Spiele, Teams und Tippspieltage nun automatisch auf strukturelle Widersprüche. Die Wettbewerbsseiten zeigen den Prüfstatus transparent an, ohne Inhalte zu schätzen oder das bestehende Grundlayout zu verändern.
