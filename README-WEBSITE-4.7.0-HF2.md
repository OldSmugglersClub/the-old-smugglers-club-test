# Website 4.7.0-HF2

Produktions-Hotfix für die mobile Spieltagsliste.

## Verhalten

- 1 Spiel: kompakte Liste, kein interner Scrollbereich.
- 2 Spiele: beide Begegnungen vollständig sichtbar.
- 3 oder mehr Spiele: begrenzte, intern scrollbare Liste mit ungefähr zwei gleichzeitig sichtbaren Begegnungen.

Desktop und sämtliche Daten-/Berechnungslogik sind unverändert.
