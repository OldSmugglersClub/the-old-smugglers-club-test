Gezielter Darstellungs-Hotfix für die Event-Countdown-Kachel.

Die Event-Infobox unterhalb des Zählerblocks erhält mehr vertikalen Abstand. Dadurch wirkt die Kachel ruhiger und die Informationsbereiche sind klarer getrennt.

- Grid und Navigation

- Spieltagskachel, Highscore und Hall of Fame
