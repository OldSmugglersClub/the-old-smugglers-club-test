# Website 4.7.0-HF1

Produktions-Hotfix für die mobile Spieltagskachel.

## Änderung

- Die intern scrollbare Liste der weiteren Spiele zeigt auf Smartphones mindestens zwei vollständige Begegnungen gleichzeitig.
- Die Spieltagskachel wächst mobil entsprechend in der Höhe.
- Tagesüberschriften bleiben beim internen Scrollen sichtbar, ohne die Spielzeilen zu überdecken.

## Unverändert

- Desktopdarstellung
- Spieltags- und Eventlogik
- Datenquellen
- Wappen, Buttons, Highscore und übrige Startseitenkacheln
