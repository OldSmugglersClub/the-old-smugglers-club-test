# Website 4.7.2-HF3-HF2

Hotfix auf Basis 4.7.2-HF3-HF1 für Highscore-Gleichstände.

## Änderungen
- Startseiten-Highscore: mehrere Rang-1-Spieler werden gemeinsam dargestellt.
- Highscore-Zusammenfassung: mehrere Rang-1-Spieler werden als „Gemeinsam Führende“ angezeigt.
- Bei mehr als drei gemeinsam Führenden wird kein zufälliges Dreierpodium hervorgehoben.
- Einzelne Führung, Teamwertung und Bonuswertung bleiben unverändert.
- Keine Änderung an Grid, Navigation, HTML-Grundlayout, CSS oder Admin.
