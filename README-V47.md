# Version 2.47 – Technischer Feinschliff

Diese Version baut vollständig auf Version 2.46 auf.

## Änderungen

- Browserseitige Ressourcenhinweise für zentrale Skripte und JSON-Daten ergänzt.
- Tastaturfokus und Touch-Bedienbarkeit der gemeinsamen Wettbewerbsoberfläche verbessert.
- Rücksicht auf `prefers-reduced-motion` erweitert.
- Defensive Initialisierung verhindert doppelte Modulstarts.
- Dokumentation, Versionsstand und Änderungsprotokoll aktualisiert.

## Unverändert

- Grundlayout
- Raster und Kachelgrößen
- Abstände
- freigegebene Gestaltung
- zentrale Datenstruktur und Inhalte
