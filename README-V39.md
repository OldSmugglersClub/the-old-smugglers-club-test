# Version 2.39 – Wettbewerbs-Lagebild

Diese Version ergänzt auf allen Wettbewerbsseiten eine einheitliche Momentaufnahme.

## Angezeigte Informationen

- letztes bestätigtes Ergebnis
- nächste bestätigte Partie
- nächster noch offener Eintrag
- Fortschritt innerhalb der zentral erfassten Spiele
- Anzahl der erfassten Wettbewerbsabschnitte

Die Auswertung verwendet ausschließlich `spieldaten.json` und `teams.json`. Nicht vorhandene Angaben werden nicht geschätzt.
