# Website 4.7.0-RC6-HF3-TEST

Gezielter Hotfix für die Spieltagskachel.

## Änderungen

- Heim- und Auswärtsteamnamen verwenden in allen Desktop-Spielzeilen feste, linksbündige Textachsen.
- Unterschiedlich lange Vereinsnamen erzeugen keinen sichtbaren seitlichen Versatz mehr.
- Die hervorgehobene Begegnung wird zustandsabhängig als „Aktuelles Spiel“, „Nächstes Spiel“ oder „Letztes Spiel“ bezeichnet.

## Unverändert

Grid, Kachelgröße, Navigation, Spieltagsdaten, Countdown-Logik, Highscore und Hall of Fame.
