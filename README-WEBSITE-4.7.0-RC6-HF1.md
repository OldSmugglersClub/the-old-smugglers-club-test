# Website 4.7.0-RC6-HF1-TEST

Gezielter Hotfix für den LIVE-Zustand der permanenten Event-Countdown-Kachel.

## Änderung

Während mindestens eine Begegnung läuft, werden die vier Zählerfelder nicht mehr mit `00` angezeigt. Der Zählerbereich zeigt stattdessen zentral:

- `JETZT LIVE` bei einer laufenden Begegnung
- `N SPIELE LIVE` bei mehreren gleichzeitig laufenden Begegnungen

Die bestehende Infobox darunter nennt weiterhin Spieltag und Anzahl beziehungsweise Paarung.

## Unverändert

Grid, Kachelgröße, Eventauswahl, Zeitlogik, Spieltagskachel, Highscore, Navigation und zentrale Datenstruktur bleiben unverändert.
