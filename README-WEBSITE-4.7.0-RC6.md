## Erwartung

- Kachel zeigt den vollständigen Tippspieltag, nicht nur ein Einzelspiel.
- Tagesgruppen erscheinen chronologisch.

- Fünf Spiele vom Samstag 15:30 Uhr erscheinen LIVE.
- Das Samstagabendspiel und beide Sonntagsspiele bleiben terminiert.

- Scrollbereich bleibt innerhalb der unveränderten Kachelhöhe.
- Countdown und Spieltagskachel verwenden denselben zentralen Terminstand.

Ein separater Smugglerauftrag wird nicht in diesen Bundesliga-Tippspieltag gemischt. Das folgt der verbindlichen Regel, dass verschiedene Kicktipp-Tippspieltage getrennt bleiben.
