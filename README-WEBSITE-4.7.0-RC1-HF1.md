# Website 4.7.0-RC1-HF1-TEST

Gezielter Hotfix für den RC1-Punktetest.

## Korrekturen

- Podium, Führender, Tabelle und Pagination verwenden dieselbe stabil sortierte Rangliste.
- Sortierung: offizieller Rang aufsteigend; bei Ranggleichheit Punkte absteigend; danach Name alphabetisch.
- Nullstand bleibt alphabetisch und ohne scheinbares Podium.
- Die dekorative Tabellenmarke „SCHIFFSREGISTER“ wird nicht mehr über Tabellenköpfen angezeigt.

## Unverändert

Grid, Navigation, Kachelgrößen, JSON-Struktur, Teamwertung, Startseitenkachel und Hall of Fame.

## Installation

Alle Dateien des Updatepakets in das lokale Testrepository kopieren und vorhandene Dateien ersetzen. Vor dem Commit gemäß Hotfix-Workflow den GitHub-Desktop-Diff prüfen.
