# Version 2.38 – Wettbewerbs-Terminstatus und Datenqualität

Diese Version vereinheitlicht die Darstellung zentral hinterlegter Spiele auf den Wettbewerbsseiten.

## Neu

- Statuskennzeichnung für beendet, zeitgenau terminiert und Termin offen
- filterbarer Spielplan auf den Wettbewerbsseiten außerhalb der Bundesliga
- strukturierte Prüfung auf fehlende Team- und Datumsangaben
- Anzeige des jüngsten hinterlegten Quellenstands
- klare Trennung zwischen struktureller Datenprüfung und externer Terminprüfung

Das freigegebene Grundlayout, die Kachelgrößen und andere Websitebereiche bleiben unverändert.
