# Website 4.7.0-RC5-TEST

Dieser Teststand erweitert die bestehende Startseitenintegration ohne Änderung des Grundlayouts.

## Testumfang

1. Team-Siegel in allen Zeilen der Spieltagsliste.
2. Permanenter Countdown bis zum nächsten bestätigten Event.
3. Live-Zustand bei laufendem Event.
4. Automatischer Übergang zum nächsten Event.
5. Definierter Leer-/Saisonendzustand.

Die zentrale Datenquelle bleibt `website-view.json`. Legacy-Dateien bleiben als Rückfallquelle erhalten.
