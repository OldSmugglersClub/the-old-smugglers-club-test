# Website 4.7.0-RC8.2-HF1-TEST

## Zweck
Gezielter Hotfix für die redaktionelle Reihenfolge auf den Wettbewerbsseiten.

## Änderungen
- Bundesliga: Die technische Box „Datenmanagement“ wird auf der öffentlichen Seite nicht mehr angezeigt.
- Dynamo Dresden / Smuggleraufträge: Die Regeln werden vor der dynamischen Liste der 34 Aufträge dargestellt.

## Unverändert
- zentrale Spieldaten
- Punkteberechnung
- Wettbewerbsnavigation
- Grid und Kachelgrößen
- Grundlayout und Design
