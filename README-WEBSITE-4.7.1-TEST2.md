# The Old Smugglers Club – Website 4.7.1-TEST2

Dieses Paket ist ein vollständiger Teststand auf Basis von Website 4.7.0-HF2.

## Zweck
Qualitätsrelease zur Entfernung sichtbarer Entwicklerinformationen, Vereinheitlichung der Versionsanzeige und gezielten mobilen Typografiekorrektur.

## Installation des Updatepakets
1. Bestehenden Website-Stand sichern.
2. Inhalt des Updatepakets direkt in das Stammverzeichnis des GitHub-Repositories kopieren.
3. Vorhandene Dateien ersetzen.
4. Commit und Push durchführen.
5. VERSION.txt direkt im Browser prüfen.
6. Desktop- und Mobiltest gemäß Testprotokoll durchführen.

## Wichtig
Der enthaltene Stand ist nicht FINAL. Er darf erst nach bestandener Abnahme als 4.7.1 FINAL freigegeben werden.
