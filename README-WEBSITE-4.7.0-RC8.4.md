# Website 4.7.0-RC8.4-TEST

## Zweck

Die nicht vollständig automatisierte Smugglerauftragskachel wurde von der Startseite entfernt. Die Smuggleraufträge bleiben über die Wettbewerbsübersicht und die Seite „Dynamo Dresden“ erreichbar.

## Hintergrund

Die bisherige Kachel konnte Auftrag 1 darstellen, wechselte aber nicht zuverlässig als vollständige Einheit zu Auftrag 2–34. Betroffen waren unter anderem Missionsname, Gegner, Termin, Status, Geschichte und Missionsaktenlink.

## Späterer Ausbau

Eine zentrale Sondermissionskachel für Smuggleraufträge, Piratenkodex und Weihnachtsregatta ist in der ROADMAP vorgemerkt.

## Test

- Startseite enthält keine eigenständige Smugglerauftragskachel mehr.
- Hauptnavigation enthält keinen Sprunglink „Smuggleraufträge“ mehr.
- „Unsere Wettbewerbe“ → „Dynamo Dresden“ funktioniert weiterhin.
- Nachfolgende Startseitenbereiche schließen ohne Leerstelle direkt an.
- Desktop- und Mobilansicht bleiben stabil.
