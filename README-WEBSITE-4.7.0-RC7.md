# Website 4.7.0-RC7-TEST

## Zweck
Fachliche Abnahme der Saisonübersicht 2026/2027.

## Änderungen
- Terminierte Spiele werden nur bei bestätigtem Datum und bestätigter Anstoßzeit gezählt.
- Wettbewerbsstatus wird aus realen Spieldaten abgeleitet.
- Bekannte Sollsummen werden klar als Saisonplanung ausgewiesen.

## Test
1. Saisonübersicht öffnen.
2. Kennzahl „Bereits terminiert“ prüfen.
3. Status der acht Wettbewerbe prüfen.
4. Desktop-, Tablet- und Smartphone-Darstellung prüfen.
5. Links zu Wettbewerben und Kicktipp prüfen.

## Unverändert
Grid, Tabellenstruktur, Navigation, Wettbewerbsseiten und Spieltagslogik.
